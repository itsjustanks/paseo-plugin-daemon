# Fictional headless preview

Run `npm run preview:ui -- --port 43199` and open the local URL. Every host, profile, project and browser
response is fictional. No daemon, SSH target or credential service is contacted. The browser image is
an isolated local HTML screenshot; it is a static illustration renewed by the fake frame RPC.

| URL query | State and action |
| --- | --- |
| `?view=browser` | Select Watch design-review for the observer and tab selector |
| `?view=browser&browser=empty` | No browser sessions |
| `?view=browser&browser=unavailable` | Exact attach limitation |
| `?tab=processes` | Four pivots; Browsers mounts the observer only while selected |
| `?tab=connections` | Agent access off; Turn on opens full-authority confirmation; Cancel leaves it off |
| `?tab=connections&open=recovery` | Offline target; Manage → Restart Paseo worker opens confirmation |
| `?tab=connections&open=recovery&recovery=empty` | Empty saved inventory; Add connection opens the form |
| `?view=panel` | Workspace Hosts panel with Watch agent browser action |

Add `&light` for light mode. Resize to 390 × 844 for a narrow layout. Recovery Cancel is the default
focus; do not confuse fictional confirmation with a real recovery test. Native mobile and real remote
Linux behavior need separate validation. Closing the preview page releases its fake registration.

Usability fixtures: `?tab=workspaces&longnames` stresses names and action wrapping;
`&nodisk` keeps running apps visible without a disk measurement; `&nested=680` constrains the
surface inside a desktop-width viewport. Use 390, 780 and 1440 pixels in both themes.
The fictional Python HTTP server has no workspace, chat or shareable project port. It still offers
reviewed Stop. Preview/Cancel does not call monitor Stop, and monitor Stop never signals a real process.
